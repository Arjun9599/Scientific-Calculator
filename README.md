# Scientific-Calculator

🧮 Scientific Calculator (Python + Tkinter)

A modern and user-friendly Scientific Calculator built using Python (Tkinter GUI).
This project includes essential mathematical operations along with advanced scientific features and a clean UI.


✨ Features

    🔢 Basic arithmetic operations (+, −, ×, ÷)
    📐 Scientific functions:
    sin, cos, tan (Degree/Radian support)
    log (base 10)
    √ (square root)
    x² (square)
    🔁 Degree / Radian toggle mode
    🧠 Memory functions:
    M+, M−, MR
    🌗 Light / Dark mode toggle
    🔢 Mathematical constants:
    π (Pi)
    e (Euler’s number)
    🧼 Clear (C) functionality
    🎯 Clean and responsive UI


🛠️ Technologies Used

    Python 3
    Tkinter (GUI)
    Math module
